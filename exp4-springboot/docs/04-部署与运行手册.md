## 2 一键启动（开发模式）

```powershell
# 0) 切换 JDK 21（每次新开终端都要执行）
$env:JAVA_HOME = 'F:\Java\ms-21.0.12.1'

# 1) 初始化数据库（会 DROP 并重建 exp4_trade 库中的表）
cmd /c "docker exec -i mysql-rbac mysql -uroot -p123456 --default-character-set=utf8mb4 < F:\Code\java-ee-course\exp4-springboot\sql\exp4_trade.sql"

# 2) 启动后端（8080）
cd F:\Code\java-ee-course\exp4-springboot\backend
F:\Develop\Tools\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run

# 3) 另开终端启动前端（5173，已配置 /api 与 /uploads 代理）
cd F:\Code\java-ee-course\exp4-springboot\frontend
npm install      # 首次
npm run dev
```

访问 <http://localhost:5173>；接口文档 <http://localhost:8080/swagger-ui.html>。

> 演示图片：`backend/uploads/demo/` 下的 6 张图由脚本生成（不入库），若被清空，`HOME`/封面会走占位图，不影响功能。

## 3 生产打包（单 jar 方案）

```powershell
$env:JAVA_HOME = 'F:\Java\ms-21.0.12.1'

# 1) 前端构建
cd F:\Code\java-ee-course\exp4-springboot\frontend
npm run build                      # 产物在 frontend/dist

# 2) 把 dist 拷进后端静态资源目录
Remove-Item ..\backend\src\main\resources\static\* -Recurse -Force -ErrorAction SilentlyContinue
Copy-Item dist\* ..\backend\src\main\resources\static\ -Recurse -Force

# 3) 打可执行 jar
cd ..\backend
F:\Develop\Tools\apache-maven-3.9.16\bin\mvn.cmd clean package -DskipTests

# 4) 以生产配置运行（数据库密码与 JWT 密钥用环境变量注入）
$env:DB_PASSWORD='123456'
$env:JWT_SECRET='请改成至少32字节的随机字符串-0123456789'
java -jar target\exp4-springboot-1.0.0.jar --spring.profiles.active=prod
```

访问 <http://localhost:8080>（前端与接口同源，不再需要 Vite）。

### 分离部署（Nginx）

```nginx
server {
    listen 80;
    root /var/www/exp4/dist;            # 前端构建产物
    index index.html;
    location / { try_files $uri $uri/ /index.html; }   # SPA 路由回退
    location /api/ { proxy_pass http://127.0.0.1:8080; }
    location /uploads/ { alias /var/www/exp4/uploads/; }
}
```

## 6 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报 `Unknown database 'exp4_trade'` | 未初始化数据库 | 执行第 2 节第 1 步 |
| 编译报 `PaginationInnerInterceptor` 找不到 | 缺 jsqlparser 模块 | 确认 pom 中有 `mybatis-plus-jsqlparser` |
| 前端 401 循环跳登录 | 后端 token 过期或被禁用 | 重新登录；检查 `sys_user.status` |
| 上传图片 404 | 未配置 `UPLOAD_DIR` 或文件被清理 | 检查 `application.yml` 的 `exp4.upload.dir` |
| 时间显示差 8 小时 | 时区未设置 | 已统一 `serverTimezone=Asia/Shanghai` 与 Jackson 时区 |
| 8080 被占用 | 上一次进程未退出 | `netstat -ano | findstr :8080` 后结束进程 |
